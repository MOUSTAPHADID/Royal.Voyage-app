# IATA Ticketing Responsibility & Liability

**Effective Date**: April 25, 2026

## 1. Agency Responsibility

Providers using Royal Voyage's ticketing system accept full responsibility for:

- Accuracy of passenger information
- Validity of booking data
- Compliance with IATA regulations
- Proper ticket issuance procedures
- Ticket delivery to passengers

## 2. Royal Voyage's Role

Royal Voyage provides the technical infrastructure for ticket issuance but does not:

- Guarantee ticket validity
- Accept liability for passenger disputes
- Assume IATA compliance responsibility
- Guarantee Amadeus connectivity

## 3. Ticket Validation

Royal Voyage performs validation including:

- Agency status verification
- Permission checks
- Financial validation
- Price revalidation
- PCC/Office ID verification

Validation failures are communicated to Provider.

## 4. Ticket Failures

If ticket issuance fails:

- Provider is notified via webhook
- Provider must contact Amadeus support
- Provider is responsible for passenger communication
- Royal Voyage assists with technical debugging only

## 5. Ticket Disputes

Passenger disputes regarding tickets are handled by:

1. Provider (initial contact)
2. Amadeus (if technical issue)
3. Royal Voyage (if platform issue)

## 6. Liability Waiver

Royal Voyage is not liable for:

- Incorrect ticket information
- Passenger disputes
- Amadeus system failures
- IATA regulation violations
- Financial losses from ticket issues
